## 要求的变化

| 项目 | 原 v1.0.0 | 最新 v1.1.1 |
|---|---|---|
| 评分 | 代码/模型 80 + 报告/复现 20 | 核心四部分各 20（实现、训练推理、受控实验、报告）+ 扩展探索 20，共 100 |
| 扩展 | 没有独立评分及提交流程 | 可选完成，但不做最高 80/100；动机、实现、证据、分析各 5 分 |
| 分数与指标 | 描述包含模型表现 | 明确没有固定 loss/CE/PPL 门槛或分数档位，更低 loss 不直接等于更高分；负结果也可获相应满分 |
| 扩展提交 | 无独立 extension ZIP | 核心 ZIP 之外另交 extension ZIP；各自不超过 100 MB，扩展有独立 PDF、README、代码、配置、结果 |
| 新架构 | 核心只支持给定 GPT 家族 | 核心限制不变；超出核心加载器的新架构放到扩展包，附加载和评估说明 |
| GPU | 未明确 T4/BF16 接受政策 | 合规 T4/BF16 运行可接受，不要求原生 BF16 硬件支持，不需换 GPU 重跑 |
| 重交 | 一次最终提交机会 | 截止前可修改并重新提交；尝试被锁定时联系 TA 重开 |
| 已完成核心工作 | 原版格式 | 合规旧结果及有效 v1.0.0 核心 ZIP 继续接受，不因本次文档更新重训或重新打包 |

扩展仍要求固定训练 split/tokenizer/vocabulary/context、随机初始化、模型不超过 20M 参数。声称改进时要匹配 token budget 和评估协议；一个充分研究的问题即可，不按额外实验数量自动加分，同一核心实验不能没有额外贡献就重复计作扩展。
