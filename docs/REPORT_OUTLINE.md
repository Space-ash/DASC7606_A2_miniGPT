# Report 提纲（4–5 页）

本项目采用所有者提供的 4–5 页更新；页数分配是建议，不是额外课程规定。尚未运行实验，不填写虚构结果。

1. **方法（约 1 页）**：next-token objective、causal attention、MLP、pre-norm residual、生成流程与实现验证。
2. **实验设计（约 1 页）**：baseline、两个实验的单一改动与运行前假设、固定变量、token budget、环境和评估协议。
3. **定量结果（约 1 页）**：三组结果总表、学习曲线、loss/perplexity、参数量、运行时间与解释。
4. **生成分析（约 1 页）**：统一提示词和采样设置下的代表性续写；分析连贯性、重复和失败案例。
5. **讨论与复现（最多约 1 页）**：性能与计算成本、单 seed 局限、最终 checkpoint 选择及复现信息。写四页时可与生成分析合并。

完整样本保留在每个 run 的 `samples.json`。实际环境和精确命令补充进根目录 `README.md`。最终 PDF 导出为根目录 `report.pdf` 后再打包。
